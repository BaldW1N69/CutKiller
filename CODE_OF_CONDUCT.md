# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique ideas and code rather than people, and help newcomers. Harassment, discrimination and personal attacks are not tolerated.

Report unacceptable behaviour privately through a [GitHub security advisory](https://github.com/BaldW1N69/CutKiller/security/advisories/new) addressed to the maintainers; reports are handled confidentially.
